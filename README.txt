EQ Ear Trainer Web v2.1.1

概要
31-band graphic EQ を想定した、周波数・EQ聴感トレーニング用Webアプリです。
特定メーカーや特定製品を前提としない一般名称・一般仕様に統一しています。

v2.1.1 UI原則
- グレー = 停止 / 非選択
- 青 = 現在再生中
- 学習モードでは A / B のうち実際に鳴っている側だけ青表示
- A ⇄ B 切替でも、再生中側の表示が自動追従
- 停止すると A / B ともグレーへ戻る
- 音源モードでも再生・一時停止・A/B切替に表示が同期
- ブラインドでは「今A/Bどちらを聴いているか」だけを青表示し、EQ変化の答えは表示しない

主な機能
- 4モード: 単音 / 純音（31中心周波数同時） / ピンクノイズ / 音源
- 音源A/B比較
- 再生位置スライダー
- A-B区間ループ
- 31バンド周波数学習
- ブラインドテスト
- 進級試験
- 学習進捗のローカル保存
- JSONバックアップ / 復元
- PWA対応
