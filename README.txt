EQ Ear Trainer Web v2.1

概要
31-band graphic EQ を想定した、周波数・EQ聴感トレーニング用Webアプリです。
特定メーカーや特定製品を前提としない一般名称・一般仕様に統一しています。

主な機能
- 4モード: 単音 / 純音（31中心周波数同時） / ピンクノイズ / 音源
- 音源A/B比較
  A = フラット
  B = 選択帯域を ±6 dB / ±12 dB
- 再生位置スライダー
- A-B区間ループ
- 31バンド周波数学習
- ブラインドテスト
- 進級試験
- 学習進捗のローカル保存
- JSONバックアップ / 復元
- PWA対応

データ移行
v2.1では内部保存キーを
eq-ear-trainer-web-v2.1
へ変更しています。

旧バージョンの既存学習データが同じブラウザ・同じオリジンに存在する場合、
初回起動時に旧キーから新キーへ自動移行する処理を入れています。

GitHub推奨リポジトリ名

特定メーカー・特定製品の公式、公認、再現アプリではありません。
